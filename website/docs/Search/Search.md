| Do | Press |
| --- | --- |
| Open a note by name | `Mod+O` |
| Search every word | `Mod+Shift+F` |
| Find in this note | `Mod+F` |

| Type | Finds |
| --- | --- |
| `"exact phrase"` | that phrase |
| `transformer -draft` | without "draft" |
| `tag:thesis` | a tag, nested tags included |
| `path:Courses` | a folder |
| `type:experiment` | a property value |
