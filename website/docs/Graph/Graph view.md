| | |
| --- | --- |
| **Node** | a note |
| **Edge** | a link |
| **Colour** | a folder |

Click a node to highlight its links, double-click to open it. Scroll to zoom, drag to pan. **Current note** shows only what's nearby; **Options** change layout, colour and filters.

> [!note] No connections yet?
> Create one with `[[Another note]]`.
