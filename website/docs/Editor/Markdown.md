| Write | Get |
| --- | --- |
| `# Heading` … `###` | headings |
| `**bold**` `*italic*` `~~struck~~` | **bold** *italic* ~~struck~~ |
| `==highlight==` | ==highlight== |
| `` `code` `` | `code` |
| `- item` / `1. item` | lists |
| `- [ ] task` | a checklist |
| `> quote` | a quote |
| `[^1]` | a footnote |
