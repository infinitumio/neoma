---
description: A quote that starts with [!type] becomes a callout.
slug: callouts
---

```md
> [!tip] Revise little and often
> Short daily sessions beat one long cram.
```

> [!tip] Revise little and often
> Short daily sessions beat one long cram.

Types: `note` `info` `tip` `success` `question` `warning` `danger` `error` `example` `quote` `abstract` `todo` `definition` `theorem` `lemma` `proof`.

Add `-` after the type to start folded (`> [!question]- Answer`), `+` to start open. Same syntax as Obsidian and GitHub.
