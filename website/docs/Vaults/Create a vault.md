---
description: A vault is a folder of notes. Open one of yours, or let Neoma keep one.
slug: vault
demo: files
---

| On the welcome screen | You get |
| --- | --- |
| **Open local folder** | your folder of `.md` files. Desktop app, or Chrome, Edge, Brave, Arc. |
| **Create my first vault** | a vault stored inside Neoma on this device. Works everywhere. |
| **Import vault** | a vault from a ZIP or `.md` files. See [[Import and export]]. |
| **Explore demo vault** | example notes to try things on. |

Switch vaults with `Mod+Shift+O`. Removing a local folder only forgets it; removing a vault inside Neoma deletes it, so export first.

> [!tip] On a computer, prefer a folder
> Ordinary files work with any backup or sync tool. See [[Where your files are stored]].
