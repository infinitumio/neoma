description: In from ZIPs, Markdown or Obsidian. Out as Markdown, HTML, PDF or ZIP.
slug: import-export
---

**From Obsidian**: choose **Open local folder** and pick the vault. Links, callouts, tags, properties and math use the same syntax; plugins don't carry over.

**Import**: **Files → … → Import files or ZIP**, or drag files in.

| Export (`Mod+K`) | Gives |
| --- | --- |
| Export note as Markdown | the `.md` file |
| Export note as HTML | a standalone page |
| Export note as PDF (print) | a PDF |
| Export vault as ZIP | everything |
| Publish vault as a website (ZIP) | a site. See [[Publish]]. |
