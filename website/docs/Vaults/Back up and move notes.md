---
description: Your vault is a folder. Back it up like one.
slug: backup
---

- **Local folder**: Time Machine, File History, a cloud drive or Git.
- **Inside Neoma**: **Files → … → Export vault as ZIP**, weekly.
- **Another device**: open the same synced folder, or **Settings → Backups → Save vault file** and merge it on the other side. Merging never overwrites; changed notes are kept as copies.
- **Deleted a page?** **Undo** on the notice, or **Recently deleted → Restore**.
