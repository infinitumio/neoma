| If | Then |
| --- | --- |
| **Open local folder** is greyed out | use Chrome, Edge, Brave, Arc, or the desktop app |
| A link is dashed | the note doesn't exist yet; click to create it |
| Search misses a note | wait for **Indexing…** to finish |
| A vault is gone | it's per browser and device; restore your ZIP |
| A shortcut does nothing | the browser owns it; rebind it |
