Click a note, follow a `[[link]]`, type `/`. That's most of Neoma.

| Do | Press |
| --- | --- |
| New page | `Mod+Alt+N` |
| Every command | `Mod+K` |
| Open a note by name | `Mod+O` |
| Reading view | `Mod+Shift+R` |

Rename a page from its right-click menu in Files. A small **?** anywhere in the app opens the matching page here.
