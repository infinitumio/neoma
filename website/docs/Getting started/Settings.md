| Section | Has |
| --- | --- |
| Appearance | theme, font size, line width, motion, remote content |
| Editor | default view, line numbers, spellcheck, autosave |
| Files and links | attachment folder, delete confirmation, sort |
| Daily notes | folder, date format, template, `.ics` import |
| Desktop | close to tray, launch on startup |
| Backups | settings export, website, portable vault files |
| Keyboard shortcuts | rebind anything |
| About | version, updates, install as an app |

Settings live on this device. Move them with **Backups → Export settings**.
