| Do | Press |
| --- | --- |
| Command palette | `Mod+K` |
| Open a note | `Mod+O` |
| Search vault | `Mod+Shift+F` |
| New page | `Mod+Alt+N` |
| Graph view | `Mod+G` |
| Settings | `Mod+,` |
| Every shortcut | `Mod+/` |

`Mod` is `Cmd` on a Mac, `Ctrl` elsewhere. Rebind in **Settings → Keyboard shortcuts**; clear a field to restore it.
