`#thesis`, nested as `#course/physics`. Find them in the **Tags** panel or with `tag:thesis`.

```yaml
---
title: Transformer experiment 01
type: experiment
tags: [transformers]
aliases: [Attention experiment]
---
```

| Property | Used for |
| --- | --- |
| `title` | the name shown |
| `aliases` | other names links can use |
| `type` | search with `type:` |
| `date`, `due` | the calendar |
| `color` | the page colour |

Anything else is kept as written. `/property` adds one.
