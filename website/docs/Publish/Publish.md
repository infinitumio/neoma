Run **Publish vault as a website (ZIP)** from `Mod+K`. Unzip and open `index.html`, or upload the folder to any static host.

- **Homepage**: a note called `Home`, `index` or `README`.
- **Links** become working links. Links to missing notes become text.
- **Carried across**: headings, tables, code, callouts, equations, images, backlinks.

> [!warning] The whole vault goes in
> Every note in the open vault becomes a page. Keep a separate vault for what you share.

This handbook is a Neoma vault, published this way. Both are below.
