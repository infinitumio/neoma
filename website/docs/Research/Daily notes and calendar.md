```text
Calendar/2026-10-07/2026-10-07.md
```

The calendar shows exams (`exam-date:`), [[Tasks]] with a `📅` date, notes with `date:`, and imported events. **+ Event** creates an event note. Import an `.ics` file in **Settings → Daily notes**; it stays on this device and is never fetched from the internet.
